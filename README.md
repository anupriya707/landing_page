# Creative Agency Landing Page

A static, responsive landing page designed for business growth and support, built using HTML and CSS. All images are directly inserted into the HTML code.

## Features
- Unique design
- Clean, professional layout
- Directly inserted images in the HTML code

## Steps to View

1. Clone the repository:
   
   git clone <https://github.com/anupriya707/landing_page>
   

2. Navigate to the project folder:
   
   cd creative-agency
   

3. Open `index.html` in your browser:
  
   open index.html
   

4. Enjoy your landing page!

## Folder Structure

/creative-agency
├── index.html      # HTML file for the landing page
├── styles.css      # CSS file for page styling
└── images/         # Folder for images (inserted in HTML)
    ├── image1.jpg
    └── image2.jpg


## Customization

- HTML: Edit the content directly in `index.html` to customize the page.
- CSS: Update the styling in `styles.css` to adjust the layout and design.
- Images: Modify images directly inserted in the HTML or replace them with your own.
